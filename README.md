## 🚀 小白快速上手指南（下载与使用）

### 1️⃣ 如何下载项目
1. 点击 GitHub 页面右上角的绿色按钮 **`Code`**；
2. 在下拉菜单中选择 **`Download ZIP`**，将项目压缩包下载到本地电脑；
3. 将下载好的 ZIP 压缩包**解压**到任意你喜欢的文件夹（例如 `D:\DevCode\Codex换肤`）。

### 2️⃣ 快速配置与使用（简单 3 步）

* **第一步：设置图片文件夹（或单张壁纸）**
  用记事本打开 `config.json`，根据需求修改配置：
  ```json
  {
    "imageFolder": "D:\\图片\\IDE背景图",
    "imagePath": "",
    "intervalSeconds": 60,
    "opacity": 0.5,
    "debugPort": 9341
  }
  ```
  > 💡 **小提示**：
  > 
  > * **文件夹定时轮播**：只要指定 `imageFolder`，脚本就会按设定的时间间隔在文件夹内随机切换不重复的图片；
  > 
  > * **单张静态壁纸**：如果只需固定使用一张背景图，可以将 `imageFolder` 置空 `""`，并配置 `imagePath` 为单张图片的绝对路径（例如 `"imagePath": "D:\\图片\\bg.jpg"`）。

* **第二步：一键开启换肤**
  直接**双击运行 `启动换肤.vbs`** 文件！
  无需打开黑框命令行，脚本会在后台静默启动 Codex，并自动开启高清壁纸随机轮播。

* **第三步：如何恢复官方默认外观？**
  想换回官方默认外观？**直接关闭 Codex，以后正常从桌面或开始菜单重新打开 Codex 即可**，没有任何文件残留或污染！

## 🛡️ 关于 `.vbs` 启动脚本的特别说明（打消安全顾虑）

很多新手看到 `.vbs` 扩展名可能会产生安全顾虑，这里特别说明：

1. **它的唯一作用：隐藏黑色命令行窗口**
   如果直接运行 `index.mjs`，桌面上会一直留着一个黑色的 CMD 命令行窗口；而 `启动换肤.vbs` 的作用**仅仅是把这个黑色窗口隐藏起来**，让它在后台静默运行，保持你的桌面整洁。
2. **源码 100% 透明，随时可用记事本查看**
   你可以随时右键 `启动换肤.vbs` 选择“编辑”（或用记事本打开），里面**只有仅仅两行最简单的代码**，绝无任何隐藏恶意行为：
   ```vbs
   Set ws = CreateObject("Wscript.Shell")
   ws.Run "node index.mjs", 0
   ```
3. **绿色安全·文件后缀不必在意**
   本工具绝不写入系统注册表、不篡改系统文件，所有操作均在只读和纯内存渲染层面，安全软件零拦截，请放心使用！

## ⚙️ 配置文件详细参数 (`config.json`)

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `imageFolder` | String | `C:\\Users\\Public\\Pictures` | 壁纸文件夹绝对路径。脚本会自动扫描该文件夹下的 `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif` 图片进行随机轮播。 |
| `imagePath` | String | `""` | **备用单图路径**。若未配置 `imageFolder` 或文件夹为空时，降级使用此单张图片（适合固定单图换肤）。 |
| `intervalSeconds` | Number | `60` | 壁纸自动随机切换的间隔时间（单位：**秒**）。如设为 `60` 即每 1 分钟换一张，`300` 即 5 分钟换一张。 |
| `opacity` | Number | `0.5` | 应用内部面板遮罩的**不透明度**（取值范围 `0.0 ~ 1.0`）：<br>• `0.3` ~ `0.4`：背景通透、原图细节非常清晰；<br>• `0.5` ~ `0.7`：**推荐值**，兼顾美观与文字辨识度；<br>• `1.0`：完全不透明。 |
| `debugPort` | Number | `9341` | Chromium 远程调试端口，一般保持默认即可。 |
