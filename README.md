# 🎨 Codex / ChatGPT 动态轮播换肤工具 (Codex Theme Injector)

这是一个基于原生 Node.js 的免安装、零报毒 Codex / ChatGPT 桌面端换肤与动态壁纸轮播小工具。专为 **Windows 微软商店 (Microsoft Store)** 下载安装的 OpenAI Codex / ChatGPT 桌面客户端设计。

---

## ✨ 核心特性

* 🖼️ **单图 / 文件夹轮播**：支持指定本地壁纸文件夹，自动随机且不重复地轮播切换背景。
* ⏱️ **自定义轮播间隔**：可自由设定自动换图的时间间隔（单位：秒）。
* 💧 **高清透明无模糊**：去除了会遮挡画质的毛玻璃模糊效果，完美保留原图高清细节。
* ⚡ **极小资源占用**：纯原生 Node.js 实现，无内存泄漏（后台运行仅占 ~15MB 内存）。
* 🔒 **零报毒与绝对安全**：仅通过 Chromium 官方调试接口 (`--remote-debugging-port`) 向渲染层注入 CSS，不修改任何二进制文件或系统文件，火绒等安全软件零拦截。

## ⚙️ 配置文件说明 (`config.json`)

使用记事本或编辑器打开 `config.json`：

```json
{
  "imageFolder": "C:\\Users\\Public\\Pictures",
  "imagePath": "",
  "opacity": 0.5,
  "intervalSeconds": 60,
  "debugPort": 9341
}
```

### 参数详解：

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `imageFolder` | String | `C:\\Users\\Public\\Pictures` | 壁纸文件夹绝对路径。脚本会自动扫描该文件夹下的 `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif` 图片进行随机轮播。 |
| `imagePath` | String | `""` | **备用单图路径**。若未配置 `imageFolder` 或文件夹为空时，降级使用此单张图片。 |
| `intervalSeconds` | Number | `60` | 壁纸自动随机切换的间隔时间（单位：**秒**）。比如设为 `60` 即每分钟换一张图，设为 `300` 即 5 分钟换一张。 |
| `opacity` | Number | `0.5` | 应用内部面板遮罩的**不透明度**，取值范围 `0.0 ~ 1.0`：<br>• `0.3` ~ `0.4`：背景非常通透、原图细节非常清晰；<br>• `0.5` ~ `0.7`：**推荐值**，兼顾壁纸美观与聊天文字辨识度；<br>• `1.0`：完全不透明。 |
| `debugPort` | Number | `9341` | Chromium 远程调试端口，一般保持默认即可。 |

---

## 🚀 使用方法

1. 配置好 `config.json` 中的壁纸文件夹路径（`imageFolder`）；
2. 双击运行 **`启动换肤.vbs`** 即可静默启动 Codex 并应用随机壁纸轮播。

---

## 🔄 如何恢复官方默认皮肤？

本工具采用的是**完全非侵入式**的内存注入，**没有修改任何 Codex 的本地文件**：

当你**不想换肤**时：
1. 直接从开始菜单或桌面快捷方式直接重新打开 Codex（不运行换肤脚本）；
2. Codex 就会自动恢复为官方原本的默认外观。
